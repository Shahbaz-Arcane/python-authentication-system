# 🔐 Python Authentication System

A secure login system built with Python, featuring username and password validation with attempt limiting.

## ✨ Features

- ✅ Username & Password validation
- ✅ Minimum 3 characters required
- ✅ Uppercase letter requirement
- ✅ Special character requirement (!@#$)
- ✅ 3 attempts limit (Setup & Login)
- ✅ Account lockout protection
- ✅ Clean, user-friendly interface

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/Shahbaz-Arcane/python-authentication-system.git

# Navigate to folder
cd python-authentication-system

# Run the application
python auth_system.py

## 📖 Usage

1. **Account Setup**: Create username and password
2. **Login**: Authenticate with your credentials
3. **3 attempts** allowed for both setup and login
